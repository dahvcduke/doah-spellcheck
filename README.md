# Spell Checker for Dictionary of Art Historians

Go to [website](https://dahvcduke.github.io/doah-spellcheck/)

Developed at Duke University's Digital Art History and Visual Culture Research Lab

This repository contains both the workflow for the front-end interface and the back-end Python error detection pipeline.

The "Backend" directory contains all the Python workflow.

"Public" and "src" directories contain files to run the React App that hosts the front-end interface.
